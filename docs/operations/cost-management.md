# Cost management

No paid services or cloud resources are provisioned by the foundation. Local tests, deterministic optimization and shared code keep initial operating costs low.

| Item                 | Foundation expectation                        | Before enabling                                                         |
| -------------------- | --------------------------------------------- | ----------------------------------------------------------------------- |
| Expo/EAS             | Local development only; hosted usage deferred | Check current free limits/build quotas and founder budget               |
| Supabase             | No project yet; local/synthetic first         | Separate preview/production, current quotas, backups and spend controls |
| Web hosting          | No host selected                              | Verify routing, bandwidth limits, headers and logs                      |
| Analytics/monitoring | Taxonomy and privacy rules only               | Verify retention, sampling, safe payloads and monthly limits            |
| Apple Developer      | External membership required later            | Founder approves current fee and organization setup                     |
| Storage/travel APIs  | Deferred                                      | Feature need, authorized integration and explicit budget                |

Prices and free-tier limits change; this document makes no unverified price promises. Before purchasing, record provider/date, expected usage, recurring base cost, overage rates and alert thresholds. Review spend monthly during beta; avoid paid LLM calls, speculative storage and expensive enterprise infrastructure.
