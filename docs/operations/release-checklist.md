# Release checklist

- Acceptance and independent QA/security reviews complete; critical/high defects resolved.
- Types, lint, tests, web export, routing and relevant database isolation checks pass.
- Native simulator/device smoke and beta feedback recorded; installed-app and browser invitation paths verified.
- Version, build number, source revision, release notes and known limitations captured.
- Environment separation, redacted diagnostics, safe analytics, monitoring and support paths checked.
- Migration compatibility, backup/restore and forward-recovery procedure verified.
- Account deletion/export, retention, privacy policy, App Store disclosures and required permission explanations reviewed.
- Founder approves final branding, production configuration and release explicitly.
- TestFlight candidate accepted before public submission; release owner and monitoring window assigned.

Unchecked requirements are outstanding work, not assumed passes. Initial foundation is not App Store ready.
