# Initial personas

These are hypotheses, not validated customer research. See [discovery assumptions](../discovery/assumptions.md).

| Persona                             | Situation and problem                                                                  | Job to be done                                                               | MVP implication                                                                          |
| ----------------------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Group organizer (primary)           | Coordinates several working adults in a chat; repeating polls never reaches a decision | Find dates people can realistically commit to without managing a spreadsheet | Shareable invitations, response progress, explainable options, voting, confirmation      |
| Invited friend or family member     | Has private work and budget constraints; reluctant to install another app              | Respond quickly and control what others learn                                | Browser participation without registration, private constraints, clear consent           |
| Individual PTO planner (entry path) | Wants a worthwhile break within an available PTO balance                               | See a useful, accurate vacation opportunity quickly                          | Account-free recommendation, confirmed holiday assumptions, understandable PTO breakdown |

Frequent travelers optimizing miles, professional organizers, and solo travelers seeking strangers are outside initial release scope. Test the primary organizer and guest journeys before expanding segments.
