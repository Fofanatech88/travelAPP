# Mascot brief

Working name: Tavi, pending founder approval. Personality: curious, adventurous, optimistic, friendly and slightly playful. Develop an original travel companion direction using simple shapes and expressive posture; do not imitate Duolingo or other protected characters.

Foundation uses a simple original placeholder only. Final artwork, name, trademark clearance and production asset licensing remain unapproved. Mascot work is optional to functional progress.

Planned states: welcome, thinking, success, waiting for responses, trip confirmed and future memory reminder. Never imply a calculation or confirmation occurred merely because the character celebrates. Text must carry the meaning; decorative artwork is hidden from assistive technology. Respect reduced motion and avoid animations that delay actions.
