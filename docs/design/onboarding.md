# Onboarding specification

Target journey: welcome → choose individual/group intent → enter concise PTO information → receive explainable opportunity → share, save or invite. Authentication is deferred until saving to an account or creating a trip. No permissions or paywall precede the first result.

First sprint: default US federal holiday suggestions with explicit employer-observed confirmation; collect recurring workweek, available yearly PTO, preferred period and duration, with optional blackout dates. Additional annual allowance and employer dates can use progressive disclosure. Explain that suggestions are not approved leave.

Show progress without adding unnecessary screens. Preserve inputs when navigating back; associate validation errors with fields and focus the first error. Empty results explain which constraints can be edited. Results show dates, days away, PTO cost, contributing confirmed holidays and remaining balances. Share only the selected public summary by explicit action.

Validate the approximately 60-second first-value target through observed usability sessions; do not claim it from implementation alone. The foundation welcome screen is not the completed onboarding flow.
