# Design system

Direction: premium simplicity with a warm, optimistic travel personality. Working identity is configurable Project Together; Tavi is an unapproved mascot name.

Use warm cream canvas, white surfaces, deep forest primary text/actions, muted forest secondary text and restrained coral accents. The implemented token module is the source for exact values; verify text/background contrast rather than assuming palette names imply accessibility. Coral should not carry essential text until contrast is checked.

Use system fonts initially for fast loading and familiar native rendering. Use a clear display heading, readable body text and compact labels; support user text scaling without clipping. Spacing follows a consistent 4-point rhythm; cards use generous internal spacing, subtle borders and rounded corners. Shadows are decorative and never the sole separator.

Buttons and inputs have at least 44-point targets, visible focus, accessible names and clear disabled/loading behavior. Do not rely on color alone. Native safe areas and narrow browser widths guide layout. Motion is purposeful, brief and disabled/reduced for reduced-motion preferences; no animation blocks interaction.

Future primitives include inputs with inline errors, cards, navigation, modals with focus management, progress, loading, empty/error states and success feedback. Implement them only with a feature need. No payments, premature account gate or decorative mascot work may delay first value.
